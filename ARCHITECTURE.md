# vyre Architecture

The architecture documentation lives at [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md).

That file is the single source. It covers the five-tier rule, the region chain
invariant, the workspace layout, the frozen contracts, the runtime pipeline, the
two-layer optimization architecture, the dialect registry, the wire format, the
memory model, the targets, and the ownership, modularity, evidence, and failure
rules that used to live here.

For the shorter tour, start with the [`README.md`](README.md). For the reasoning
behind the design rather than its shape, read [`THESIS.md`](THESIS.md).
