# Documents exempt from the downstream-consumer naming boundary.
#
# Vyre is a substrate: its docs describe the platform's own surface, so naming a
# specific downstream product in them is real coupling and the guards reject it.
# Release runbooks are the one exception. The release train ships vyre together
# with a partner product under joint tags, so a runbook has to name the other
# repository to be followable, and the changelog has to print the identifiers a
# rename removed or a migration table is useless.
#
# This file is the one definition of the exemption. Every guard that enforces the
# boundary reads it, whether it judges the whole tree or one curated document
# set, and none of them carries a list of its own: two guards with two lists
# disagree, and a document that passes one and fails the other is exempt or not
# depending on which one ran.
#
# One workspace-relative path per line. A trailing slash exempts Markdown files
# anywhere under that directory and nothing else: a `.rs` file under an exempt
# directory stays under the guard, because source naming a product is coupling
# even when a runbook beside it is only an instruction.
