# xtask-evidence

xtask subcommands that read benchmark and release evidence provenance.

## Usage

`xtask` builds and runs this binary for the subcommands it assigns here, so the
normal entry point is `cargo xtask <subcommand>`. Running it directly works and
takes the same arguments:

```bash
cargo run -p xtask-evidence -- <subcommand> [options]
```

## Why this crate exists

A recorded measurement only describes the tree it was taken on. Deciding whether it still does means fingerprinting the source and reading the host devices, which is what `vyre-bench` owns and why this crate links it. The release checks that only read manifests stay in `xtask`.

## Layout

`xtask-evidence/src/lib.rs` holds the dispatch table, which is checked against the
subcommands `xtask` assigns to this package. `xtask-evidence/src/main.rs` is the
binary `xtask` runs.
