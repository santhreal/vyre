# Files permitted to contain unsafe code.
#
# [workspace.lints.rust] sets unsafe_code = "deny", which every member
# inherits. A file therefore cannot contain unsafe without an explicit
# allow(unsafe_code) override, so this list IS the complete unsafe surface
# of the workspace, enforced by rustc rather than approximated by grep.
#
# Adding an entry is a security review: the site needs a SAFETY comment
# naming the invariant its caller relies on. Removing unsafe from a file
# means deleting its line here in the same change.
#
# Reviewed against the tree by the lint-unsafe-budget gate, which reads the
# attribute out of code: a mention in a comment or a string is not a surface.
#   ./cargo_full run -q -p xtask --bin xtask -- lint-unsafe-budget
