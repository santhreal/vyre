# vyre-test-support

Shared test fixtures and the registry coverage closure gate.

Not here: production code, and a fixture that exists in a crate that
already owns it. Dev-dependency only. Never a runtime dependency.

## `assert_registry_closure`

`assert_registry_closure` is the canonical registry and coverage enumerator.
Call it from an owning crate's integration test, such as
`<crate>/tests/registry_closure.rs`:
```rust
const COVERAGE_WAIVER: &[&str] = &[/* builder, // reason */];

#[test]
fn every_program_builder_is_tested_registered_or_explicitly_waived() {
    let crate_dir = vyre_test_support::monorepo::vyre_workspace_root().join("vyre-libs");
    vyre_test_support::assert_registry_closure(crate_dir, COVERAGE_WAIVER, 4);
}
```

Resolve the crate directory at run time. Every checkout of this repository shares
one cargo target directory and cargo hands one checkout a binary another built,
so a directory fixed at compile time names whichever tree built last and the gate
then enumerates that tree while reporting on this one.

The helper source-enumerates every `pub fn NAME(...) -> Program` builder under the crate's
`src/` (excluding `&self` methods and `Program`-first-param transform passes) and asserts
each is registered in an `inventory::submit!` block, pinned by a parity test,
or listed in `COVERAGE_WAIVER` with a reason. Stale, covered, and unwaived
guards keep the
waiver honest and only-shrinkable; the `floor` argument fails loudly if the enumeration
silently breaks.

Enumeration reads source as text, so the gate is feature-independent and
produces the same result under every feature selection.
