# Archived book, vyre 0.7

Frozen 2026-08-15. Every file in this directory is a snapshot of what a
document said on the day it was archived. Nothing here describes the
current tree, and nothing here is maintained.

The current book starts at [the summary](../../SUMMARY.md).

## What is here

`ARCHITECTURE.md` and `lego-block-rule.md` are the two authored pages the
0.7 book still carried at freeze time. The remaining thirty pages were
deleted from the tree on 2026-08-12 and are restored here, so the record
of the 0.7 book is one directory instead of one directory plus a commit
range.

## Why the links do not resolve

These pages link to crates, modules, scripts, gates and each other as all
of those stood in 0.7. Rewriting the links to resolve against today's tree
would make the snapshot claim things it never claimed. The documentation
gate excludes archived pages from link resolution for the same reason.

## Reading one of these against the tree

Do not. A statement here is evidence about 0.7 and nothing else. Where a
0.7 page and the current book disagree, the current book was written
against source and this page was not.
