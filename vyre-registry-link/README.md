### Purpose

Own every inventory registry link anchor, report which sources a build links, and assert that each linked source reached the registry it submits into.

### Boundaries

The `registry-link` owner maintains this `registry-link` crate at `vyre-registry-link`.
Its allowed internal production dependencies are: `vyre-driver`, `vyre-driver-cuda`, `vyre-driver-metal`, `vyre-driver-reference`, `vyre-driver-spirv`, `vyre-driver-wgpu`, `vyre-foundation`, `vyre-libs`, `vyre-primitives`.
Any other normal or build dependency requires an ownership-registry change.

### Features

### Errors and unsupported behavior

A registration source that the build declared but the linker dropped, or a source that reached the registry under a different identity, is a panic naming the source rather than a registry read that silently judges a partial set.
